## 🚀 배포

### GitHub Pages로 배포

1. **GitHub 저장소 생성**
   ```bash
   # GitHub.com에서 새 저장소 생성: meme-quiz-2025-kr
   ```

2. **코드 Push**
   ```bash
   git remote add origin https://github.com/YOUR-USERNAME/meme-quiz-2025-kr.git
   git branch -M main
   git push -u origin main
   ```

3. **GitHub Pages 활성화**
   - Settings → Pages → Source: `main` branch
   - 2-3분 후 사이트 라이브!

### 또는 원클릭 배포

```bash
./deploy.sh
```
